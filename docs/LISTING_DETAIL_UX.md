# PearTree.pro — Listing Detail UX

## Desktop structure
Two-column:
- left: media gallery;
- right: title, price, seller/contact actions.

Below:
- attributes;
- location/map;
- description;
- seller profile;
- safety guidance;
- related listings.

## Mobile structure
1. gallery;
2. title/price;
3. key attributes;
4. seller;
5. sticky contact CTA;
6. description;
7. location;
8. related listings.

## Primary actions
Depending on listing type:
- Message;
- Call;
- Request quote;
- Book;
- Buy;
- Apply.

Never show irrelevant CTAs simultaneously.

## Trust
Possible signals:
- member since;
- verified;
- reviews;
- response time;
- listing ID;
- report listing.

## Safety
Context-sensitive safety tips should be available but not block browsing.

## SEO
Each public detail page needs:
- unique title;
- canonical;
- public 200 only while active/indexable;
- structured data when appropriate;
- breadcrumbs;
- category/location links;
- related entities.

Sold/expired behavior requires route policy rather than immediate 404 by default.
