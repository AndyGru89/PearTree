# Architecture Decision Records

ADRs capture material decisions that should not be rediscovered or silently changed.

## Status values
Proposed, Accepted, Superseded, Rejected.

## Naming
`NNNN-short-decision-name.md`

## Template
# ADR-NNNN — Title

**Status:** Proposed  
**Date:** YYYY-MM-DD

## Context
What problem/constraint requires a decision?

## Decision
What is being chosen?

## Consequences
Positive and negative trade-offs.

## Alternatives considered
What credible alternatives were evaluated?

## Validation
What must be proven in implementation/testing?

## Reversal / migration
How can this decision be changed later?
