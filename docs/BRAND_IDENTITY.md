# PearTree.pro — Brand Identity

## Status
Visual baseline derived from approved PearTree mockups.

## Brand idea
PearTree combines:
- local commerce;
- discovery;
- sustainability;
- trust;
- growth;
- community;
- simple marketplace operations.

The visual language should feel warmer and more human than a generic SaaS marketplace.

## Core brand assets
### Primary symbol
Pear-shaped tree containing:
- trunk/tree structure;
- leaves;
- pear fruit;
- green/yellow color family.

### Wordmark
PearTree.

Recommended use:
- dark green "Pear";
- warm brown/gold "Tree";
- cream/light backgrounds;
- simplified single-color variant for small UI contexts.

## Visual tone
- natural;
- optimistic;
- premium but approachable;
- local/community-driven;
- bright;
- trustworthy;
- slightly illustrative rather than sterile.

## Color direction
### Core
- Forest Green
- Deep Moss
- Pear Green
- Lime Accent
- Golden Pear
- Warm Cream
- Soft Sage

### Semantic use
- green: primary action/success/trust;
- gold/yellow: premium/highlight/attention;
- cream: primary canvas;
- dark forest: navigation/footer;
- red/orange only for warnings/moderation/destructive states.

## Illustration style
Use a controlled illustrated world:
- pear/tree motif;
- leaves;
- sunlight/glow;
- local landscapes;
- clipboard/search/megaphone metaphors;
- subtle eco/local visual language.

Avoid:
- childish cartoon overload;
- excessive gradients;
- overly glossy game UI;
- visual noise behind key actions.

## Photography
Listing images remain realistic and product-first.
Brand illustrations and marketplace content should not compete for attention.

## Brand voice
Simple, human and action-driven.

Examples:
- Buy. Sell. Find Near You.
- Find something worth keeping.
- Post an ad in minutes.
- Good things grow locally.

Polish product copy should be localized naturally rather than translated word-for-word.
