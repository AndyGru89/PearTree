# PearTree.pro — Operator Dashboard

## Goal
Give marketplace/operator customers a single control plane for listings, leads, users, moderation, monetization and performance.

## Navigation
- Dashboard
- Listings
- Categories
- Users
- Leads / Messages
- Moderation
- Analytics
- Transactions
- Marketing
- Settings

## Dashboard KPIs
Top row:
- active listings;
- new leads;
- revenue;
- listing views.

Each card:
- current value;
- period change;
- sparkline;
- drilldown.

## Main widgets
### Sales & Leads Overview
Chart by day/week/month.

### Top Categories
- volume;
- share;
- trend.

### Current Plan
- plan;
- usage;
- upgrade/manage.

### Recent Messages
Latest lead/user conversations.

### Moderation Queue
Approve/reject flagged/pending content.

### Traffic / Activity
Map or geography summary where useful.

## Information architecture rule
Dashboard shows operational summary, not every metric.

Detailed modules contain deeper analytics.

## Role behavior
Visible modules and actions depend on RBAC.

## Visual direction
- dark forest sidebar;
- cream content canvas;
- green/gold KPI accents;
- compact card system;
- subtle leaf branding only in non-critical decorative areas.

## Performance
Dashboard must remain functional without decorative illustrations.
