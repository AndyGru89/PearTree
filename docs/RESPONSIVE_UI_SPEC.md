# PearTree.pro — Responsive UI Specification

## Target widths

Primary design targets:
- 390 px mobile;
- 430 px large mobile;
- 768 px tablet portrait;
- 834 px tablet;
- 1280 px desktop;
- 1440 px desktop;
- 1728+ px wide desktop.

These are validation targets, not hardcoded CSS breakpoints.

## Homepage

### Mobile
- compact header;
- hero stack;
- search in vertical layout;
- illustration reduced or moved below search;
- horizontal category scroller;
- 2-column listing cards where practical, otherwise 1-column;
- sticky Post Ad action optional.

### Tablet
- 2-column hero where space permits;
- 3–4 listing cards;
- condensed category grid.

### Desktop
- full hero;
- 5–6 listing cards;
- wide category row/grid;
- richer illustration.

## Dashboard

### Mobile
Dashboard becomes task-oriented:
- KPI cards in horizontal scroll or stacked;
- charts full-width;
- moderation/messages as cards;
- sidebar becomes drawer;
- only essential controls visible.

### Tablet
- collapsible sidebar;
- 2-column dashboard grid.

### Desktop
- persistent sidebar;
- 12-column grid;
- 3–4 KPI cards in a row.

## Listing detail

Mobile:
- gallery first;
- sticky contact CTA;
- metadata condensed;
- seller card below description.

Desktop:
- gallery + details split;
- contact/seller panel can be sticky.

## Post Ad

Mobile:
- one field group per viewport;
- sticky Next button;
- image upload optimized for camera/gallery.

Desktop:
- form + contextual preview/help when useful.
