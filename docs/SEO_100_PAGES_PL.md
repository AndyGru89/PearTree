## Publishing waves

### Wave 1 — first 15
Pages 1, 4, 7, 10, 11, 12, 18, 21, 23, 31, 32, 33, 51, 61, 71.

Goal: define category, validate commercial messaging and build topical anchors.

### Wave 2
Add comparisons, monetization and first tools once PearTree screenshots/product evidence exist.

### Wave 3
Expand vertical/use-case pages only after the product has real reference implementations.

## Quality rule

Do not publish competitor, vertical or feature pages before PearTree has enough factual product substance to support them. A smaller set of strong pages is preferable to a large set of generic AI-generated copy.
