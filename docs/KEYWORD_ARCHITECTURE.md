# PearTree.pro — Keyword Architecture

## Purpose
Build a search-demand map before writing large amounts of content.

## Cluster model

### Cluster 1 — product/category
Intent: commercial.
Examples:
- marketplace software;
- marketplace builder;
- directory software;
- business directory software;
- portal builder;
- membership directory software;
- white-label marketplace platform.

### Cluster 2 — use case
Intent: commercial investigation.
Examples:
- service marketplace builder;
- local business directory builder;
- property directory software;
- agency portal platform;
- membership site with directory;
- marketplace for services.

### Cluster 3 — outcome/problem
Intent: informational/commercial.
Examples:
- how to build a marketplace;
- how to create a business directory;
- how to monetize a directory;
- how to sell leads online;
- how to build local portal;
- how to launch vertical marketplace.

### Cluster 4 — feature
Intent: comparison/solution.
Examples:
- marketplace CRM;
- directory lead management;
- marketplace SEO;
- marketplace analytics;
- white-label portal software;
- custom domain marketplace;
- directory API.

### Cluster 5 — alternative/comparison
Intent: high commercial.
Examples:
- Sharetribe alternative;
- Brilliant Directories alternative;
- Softr alternative for marketplace;
- Webflow directory alternative;
- marketplace software comparison.

## URL architecture for PearTree.pro

Suggested acquisition structure:

- `/`
- `/product`
- `/pricing`
- `/solutions/{use-case}`
- `/industries/{vertical}`
- `/features/{feature}`
- `/compare/{competitor}`
- `/guides/{topic}`
- `/blog/{article}`
- `/templates/{template}`
- `/calculators/{tool}`

Avoid creating a new page for every minor keyword variation.

## Keyword-to-page rule
One primary search intent = one canonical page.

Secondary synonyms belong on the same page unless SERP evidence shows materially different intent.

## Research requirements before publishing
For each cluster:
- target locale/language;
- query;
- intent;
- SERP type;
- top competitors;
- likely landing-page format;
- business value;
- unique evidence/tool/data PearTree can add.

Search volume is useful but not sufficient. High-intent low-volume terms can be more valuable than broad traffic.
