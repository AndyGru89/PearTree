# PearTree.pro — Mobile UX Specification

## Product direction
Mobile experience is not a compressed desktop site.

Primary mobile jobs:
- browse;
- search;
- save;
- message/call;
- create listing;
- manage own listings;
- profile/account.

## Bottom navigation
Recommended:
- Home
- Saved
- Sell (+ central CTA)
- Messages
- Profile

## Home
- logo/header;
- search;
- horizontal categories;
- featured cards;
- recent/local listings;
- filters.

## Search
Full-screen filter experience:
- query;
- category;
- location/radius;
- price;
- condition;
- attributes;
- sort.

## Listing detail
Sticky bottom contact CTA.

## Create listing
Step-by-step single-column form with:
- progress;
- autosave;
- large tap targets;
- camera/gallery upload;
- preview before publish.

## Messaging
Conversation list + thread.
Future real-time architecture can use Durable Objects if justified.

## Performance
Mobile images must be responsive and optimized.
Avoid large background illustration assets inside scroll-heavy product screens.

## PWA
PWA may be considered later; do not block MVP on native-app-like features.
