## Mockup acceptance criteria

Every page mockup must show:
- desktop;
- tablet or responsive behavior;
- mobile;
- loading state;
- empty state;
- error state where meaningful;
- primary success state;
- destructive confirmation where relevant.

A mockup without operational states is not implementation-ready.
